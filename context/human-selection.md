# Human Selection

Use this to record the human taste decision before implementation hardening.

## Required artifact

`frontend-artifacts/human-selection.md`

## Required status

One of:

```txt
APPROVED
APPROVED_WITH_NOTES
REJECTED
NEEDS_MORE_VARIANTS
PROVISIONAL
```

Only `APPROVED` and `APPROVED_WITH_NOTES` can pass final validation.

## Principle

The agent can create options and critique resemblance. The human selects for taste, presence, and product fit.
