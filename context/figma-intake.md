# Figma Intake

When Figma context is available, extract:

- Frames/screens.
- Components used.
- Tokens or styles.
- Text styles.
- Color variables.
- Auto-layout behavior.
- Breakpoint assumptions.
- Prototype interactions.
- Missing states.

Implementation should follow the design system over one-off frame measurements when there is a conflict, unless the task explicitly says to match the mock exactly.
