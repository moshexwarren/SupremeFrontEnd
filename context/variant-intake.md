# Variant Intake

Use this when a task is open-ended or the user asks to make a UI better, premium, modern, calm, bold, polished, or distinctive.

## Required artifact

`frontend-artifacts/variant-board.md`

## Minimum variants

- 3 for ordinary open-ended UI.
- 4 for high-stakes homepages, landing pages, dashboards, brand-defining pages, or if the first three are too similar.

## Distinction requirements

Variants should differ in at least two of:

- Information architecture.
- Composition.
- Density.
- Visual rhythm.
- Typography treatment.
- Navigation model.
- Hero/header strategy.
- Card/list/table strategy.
- Interaction feel.

Do not present “same layout, different colors” as separate directions.
