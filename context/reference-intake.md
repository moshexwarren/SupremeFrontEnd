# Reference Intake

Use this when the UI quality depends on taste, mood, layout presence, or matching a known direction.

## Required artifacts

Create `frontend-artifacts/reference-brief.md` and, when possible, place images in:

```txt
frontend-artifacts/references/
```

## Ask / infer

- What product category is this?
- What should the UI feel like?
- Which references represent the desired composition or mood?
- Which references should be avoided?
- Which traits should be borrowed?
- Which traits must not be copied?
- How bold can the direction be?
- Is this maintenance work or concept work?

## Important

Reference assets are visual anchors. They are not licenses to copy proprietary screens, logos, illustrations, or brand signatures.
