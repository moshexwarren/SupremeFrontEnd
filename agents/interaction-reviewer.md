# Interaction Reviewer Agent

## Role

Verify that the screen behaves like a real product.

## Required checks

- Primary CTA works or has correct disabled/loading behavior.
- Secondary actions are clear.
- Empty states are useful.
- Error states are useful.
- Loading states do not cause layout chaos.
- Forms validate clearly.
- Navigation works.
- Mobile interactions are usable.
- Hover/focus/active states are present where applicable.

## Output

`frontend-artifacts/interaction-review.md`
