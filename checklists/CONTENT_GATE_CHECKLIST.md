# Content Gate Checklist

Before saying a phase is complete, verify:

- required files exist
- required sections are filled
- no placeholder-only content
- no vague words without mechanisms: premium, modern, clean, beautiful
- numeric/token guidance exists where relevant
- slop risks are specific
- do-not-copy list is explicit
- design-brain judgments are applied, not copied
- user approval is recorded where required
- screenshot review is marked pending if not done
