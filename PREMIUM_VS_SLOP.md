# Premium vs AI Slop

## Core idea

AI slop is usually not one bad feature. It is the accumulation of ungoverned, generic, surface-level decisions.

A gradient is not automatically slop. Cards are not automatically slop. Icons are not automatically slop. They become slop when clustered without purpose.

## Generic AI slop clusters

### Cluster 1 — Purple SaaS Soup
Signals:
- centered hero
- purple/blue gradient
- vague headline
- pill CTA
- floating dashboard/cards
- random icon tiles
- “AI-powered personalized journey” copy

Cluster penalty: +3 if 4+ signals appear.

Fix:
- remove generic gradient/dashboard/icon cluster
- rebuild around product-specific user state
- use one clear primary action and restrained color

### Cluster 2 — Everything Is a Card
Signals:
- every section boxed
- cards inside cards
- equal card weight for unequal content
- fake feature grid
- dashboard panels for non-dashboard product

Fix:
- remove cards that do not group a meaningful content unit
- use open layout, headings, spacing, dividers

### Cluster 3 — Fake Premium Minimalism
Signals:
- huge whitespace
- tiny gray copy
- low contrast
- vague luxury tone
- unclear CTA
- too little useful information

Fix:
- add clarity, contrast, specific information, and visible action

### Cluster 4 — Wellness Cliche
Signals:
- pastel blobs
- leaf/heart/brain icons
- “journey/growth/healing” vague copy
- generic smiling illustrations
- soft gradient everywhere

Fix:
- replace with specific therapeutic/decision support language
- use calmer, less performative visual language

### Cluster 5 — Reference Mashup Soup
Signals:
- one site’s colors
- another site’s typography
- another site’s card shape
- another site’s animation
- no unified system

Fix:
- assign each reference to a layer
- translate into local tokens/components only

## Premium signals

Premium does not mean fancy. Premium means intentional.

Signals:
1. one clear focal point
2. typography roles are controlled
3. spacing has rhythm
4. color has roles
5. components are reused
6. cards/surfaces have purpose
7. motion supports orientation/feedback
8. copy is specific and calm
9. states are complete
10. mobile/RTL are first-class
11. important text is readable
12. fewer, stronger elements
13. empty/error/loading states feel designed
14. the product feels specific, not generic

## Slop score

Score each 0–2:

1. generic SaaS language
2. random decorative elements
3. weak hierarchy
4. inconsistent spacing
5. too many card containers
6. overuse of gradients/shadows/glass
7. vague copy
8. unclear user path
9. inconsistent components
10. poor real-content resilience

Add +3 cluster penalty if 4+ signals from any cluster appear.

Threshold:
- 0–3: clean
- 4–5: needs polish
- 6–8: slop risk, must revise
- 9+: unacceptable

## Premium score

Score each 0–2:

1. restraint
2. clarity
3. emotional fit
4. component consistency
5. typography quality
6. spacing rhythm
7. real-content handling
8. accessibility
9. mobile/RTL quality
10. trust/product specificity

Threshold:
- 18–20: excellent
- 15–17: acceptable
- 12–14: weak, revise
- <12: not acceptable
