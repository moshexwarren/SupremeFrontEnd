# Motion Rules

Motion should clarify state, not decorate randomly.

Use motion for:

- Button feedback.
- Dialog entrance/exit.
- Toast appearance.
- Expanding panels.
- Loading transitions.

Avoid:

- Long ornamental animations.
- Animating layout in a way that causes jank.
- Motion that hides slow loading.
- Multiple competing animation styles on one screen.

Respect reduced-motion preferences.
