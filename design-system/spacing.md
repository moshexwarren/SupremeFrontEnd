# Spacing Rules

## Principle

Spacing should create rhythm, hierarchy, and calm. Do not use random pixel values.

## Preferred scale

Use 4px-based spacing:

- 4px: tiny internal detail.
- 8px: tight relationship.
- 12px: compact grouping.
- 16px: default element spacing.
- 24px: section grouping.
- 32px: major panel spacing.
- 48px: page section separation.
- 64px+: hero or major breathing room.

## Rules

- Related items should sit closer than unrelated items.
- Cards in the same grid should share padding.
- Vertical rhythm should be more deliberate than horizontal rhythm.
- Avoid mixing many spacing values on one screen.
- Prefer fewer, repeated spacing values.
- Mobile spacing may compress, but hierarchy must remain clear.

## Common defects

- Cards too cramped.
- Hero section too tall without purpose.
- Random gaps from default margins.
- Buttons floating with no alignment logic.
- Form labels too far from inputs.
- Tables with dense rows and weak grouping.
