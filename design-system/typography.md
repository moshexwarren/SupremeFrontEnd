# Typography Rules

## Principle

Typography should make the page understandable before the user reads every word.

## Rules

- Use a limited type scale.
- Use no more than two font weights inside a section unless justified.
- Page title must be visually dominant.
- Section titles must be clearly below page title hierarchy.
- Body text should be comfortable to scan.
- Labels and metadata should be smaller but still readable.
- Avoid all-caps except for small labels or badges.
- Line length should stay readable.

## Suggested scale

- Display: 48–64px
- Page title: 32–44px
- Section title: 22–28px
- Card title: 16–20px
- Body: 14–16px
- Metadata: 12–14px

## Hebrew / RTL note

For Hebrew interfaces:

- Avoid overly condensed fonts.
- Check punctuation direction.
- Ensure numerals and mixed English/Hebrew labels render cleanly.
- Alignment should be intentionally right-aligned where appropriate, not accidentally inherited.
