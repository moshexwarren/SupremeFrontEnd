# Layout Recipes

## App shell

- Stable header/sidebar structure.
- Content max width should be intentional.
- Main content starts at a predictable vertical position.
- Avoid edge-to-edge text on desktop.
- Avoid cramped cards on mobile.

## Landing page rhythm

1. Hero.
2. Problem or context.
3. Solution cards.
4. How it works.
5. Trust/support.
6. CTA.

## Dashboard rhythm

1. Page header.
2. Primary action.
3. Summary cards.
4. Main work area.
5. Secondary information.

## Mobile behavior

- Primary action remains discoverable.
- Nav collapses predictably.
- Tables become cards, horizontal scroll, or compressed rows by explicit choice.
- Tap targets at least 44px high where feasible.
- Inputs use full width unless there is a strong reason not to.
